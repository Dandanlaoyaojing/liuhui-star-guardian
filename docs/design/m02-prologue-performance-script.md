# M02 序章演出脚本（动画 + 莱米×星光棒互动）

> 2026-07-18。**纯演出层**：序章的规则、节拍、数值（`lifeMax`/`freezeThreshold`/`rekindleBeats`/`adjacencyRadius`/`beatSeconds`）一个都不动——它们被 config 与测试钉死。本脚本只填 spec §5.3 "莱米发抖/烤爪动画后补" 留下的空位，全部挂在 `M02PrologueSession` 既有事件上。
> 基调：Arrog 式克制。演出永不锁输入、永可被玩家操作打断；莱米不解说玩家的失败（安静原则，spec §1.4.6）。雾在本关不露面——只有"冷"（正典：M02 是雾的匿名作案）。

## 逐拍分镜

### 第 0 拍 · 三道流星（新增开场，与第 1 拍并行，不加等待）

- **画面**：右上天际——M01 齿轮星的方向——三道弧线先后滑落（正典追认 §1.4：M01 修复时溢出的星光）。一长两短，尾迹是水彩颗粒。落点在画面中带、彼此错开；落地不爆，各自弹跳一次，缩成三粒将熄的余烬。
- **声音**：三声很轻的下滑音，一声比一声低。
- **母题呼应**：这是"三道光（一长两短）"母题的第三现——第一现在 M01 通关过场的星光云海（全屏），第二现在星图解锁演出（宏观，见下节"M01→M02 衔接链"），此处是近景落地。三个尺度共用同一形状与同一组音色，玩家无需文字即知余烬来历。

## M01→M02 衔接链（通关动画结尾走进 M02 故事）

1. **视频内（现片不动）**：14.35s 过场照播至"淡出泛白"，泛白即交接口。P2 可选：重制片尾最后一秒，让三粒光从云海右上析出划走；链条不依赖此项。
2. **星图解锁演出（P0，引擎实时，约 2.5-3s，可点击跳过）**：ToolCard 收下→回星图→静半拍→刚修复的齿轮星迸出**三道细弧光（一长两短）**，划过星图坠向邻近暗星；落点不爆花，暗星边缘留三点微光余韵，暗星由死灰转入**呼吸**（=可进入），周围星图灰雾退开一小圈。无文字、无弹窗——**星星被光唤醒即解锁**。声音=三声下滑音的远景版（与本序章第 0 拍同音色，更轻更远）。实现：StarMap 表现层 tween + particle-flow，解锁状态机不动。
3. **十星通用解锁语言**：此后每关通关回星图皆为"刚修复的星迸光→飞向下一颗→唤醒之"；光的形态可随关卡母题变化（各关立项定），"解锁=上一关的光唤醒下一颗星"不变——星图解锁本身就在演"传灯"。

### 第 1 拍 · 走入与发抖

- 莱米从左侧 `walk` 走入，步子比 M01 略碎（冷）。到位后不进 `idle`——直接进新动作 **`shiver`** 循环：耳朵沉在背后、脖子缩着、小幅不规则断续颤，每隔几秒夹一次快速两连抖。
- 可选粒子：一小口白色呼气雾，每 4-6 秒一次，淡入淡出。
- 行走时不抖（避免 walk×shiver 帧组合爆炸）；只在站立位抖。

### 第 2 拍 · 拔棒（工具到手）

- **暗棒零反馈原则**：石缝里的星光棒暗色斜插，只有一道极淡冷反光——此刻它只是一根棍子，无自发光、无呼吸、无提示。工具的"死"要死得彻底，点亮那一刻才有对比。
- 玩家点棒 → 莱米 `walk` 走近 → 新动作 **`wandpull`**：双爪上握、蹬地、一次拔出，拔出瞬间小半步后仰稳住。棒 prop 从插地角度旋到举起角度，跟手锚点。
- 紧接新动作 **`wandwave`**：举棒向星网方向挥两下——第一下满弧，第二下弧线明显变小（没劲了），收在爪子垂下的姿势。棒尖：什么都不发生。半拍停顿，莱米低头看一眼棒尖（`nodside` 前几帧或停帧）。
- **声音**：拔出=一声短促石屑摩擦；两下挥动=风声两声、第二声更轻；无反应=**留白不配音**，沉默本身是效果。

### 第 3 拍 · 余烬将熄（逻辑已实现）

- 熄灭演出：不是关灯，是"缩"——光晕半径在三次呼吸内收到零，留一粒炭点；复燃=炭点里眨出一星火，两拍长回。
- 莱米：站在棒旁 `shiver`。**仅第一次**有余烬熄灭时插一次 `puzzled`（歪头看那粒炭点），然后回 `shiver`。不重复。

### 第 4 拍 · 孤烬必灭

- 被拖的余烬微微拉长成泪滴形（拖拽形变，光晕跟随）；半路凉掉时光晕内收成炭点。
- 莱米：目送，**不加动作**——玩家的失败不需要兔子解说。

### 第 5 拍 · 两颗仍灭

- 两烬靠近时相互探出极细的**光茸**（互撑半径的可视化），但两茸接不成环——一起转暗。
- 莱米：无新增动作。

### 第 6 拍 · 三颗成簇长明

- 第三颗进半径的瞬间：三对光茸同时接通，光晕从"呼吸收缩"切换为"稳定柔光"（与主谜题冻结柔光同参——已入正典），火簇中心升起一缕细暖光。
- 莱米：**`earsup`**——耳朵竖起，`shiver` 循环淡出。**这是莱米整个序章第一次不冷。**
- 声音：三音合鸣的一声暖和弦，很短。

### 第 7 拍 · 烤爪与点棒（标题兑现拍）

- 莱米自动凑近火簇半步，进新动作 **`warmpaws`** 循环：俯身、双爪伸向火簇、缓慢翻转爪心——**动画拍点与火簇呼吸 pulse 对齐**（"点亮你温暖我"第一次兑现在身体上）。
- 玩家点火簇 → 莱米以 `crouch` 前段俯身（复用），棒 prop 尖端探入火簇 → **火苗顺棒身爬升**：0.6s 光沿棒走线（particle-flow），到顶端软软绽开 → 整棒转入亮态（暖蜜金、微呼吸）。
- 莱米 `earsup` 短放 + 半步后仰——是**惊喜**，不是受惊（不用 `startle`）。
- 棒尖电量光点**次第**浮出，一粒一声很轻的上行音阶。
- 星网从棒尖方向荡开一圈涟漪，第一板浮现。
- 声音：爬升=渐强细摩擦音；绽开=一声软钟音；光点=琶音。

### 亮棒后的微生命（P2 可选，贯穿主谜题）

- 焰苗随莱米移动有约 0.2s 拖曳惯性。
- 棒静止较久时，焰苗朝最近可点星极轻微倾斜一次——diegetic 软提示。**可选项**，立项时再定，不抢提示系统的活。

## 新增动画资产清单（即梦管线）

| 动作 | 类型 | 帧数建议 | 优先级 | 备注 |
|------|------|---------|--------|------|
| `shiver` 站立发抖 | loop | 12-16 | P0 | 耳贴背+缩脖+断续颤；循环动作等高归一 |
| `wandpull` 拔棒 | oneshot | 20-24 | P0 | 双爪上拔+后仰半步；**不带棒生成** |
| `wandwave` 挥棒两下 | oneshot | 16-20 | P0 | 第二下明显没劲；**不带棒生成** |
| `warmpaws` 烤爪 | loop | 12-20 | P0 | 拍点与火簇 pulse 对齐 |
| `wanddip` 点棒俯身 | oneshot | 12-16 | P2 | 先用 `crouch` 前段复用顶位 |

复用：`walk` `puzzled` `earsup` `crouch` `nodside`；`celebrate` 留给通关，序章不用；`startle` 语义是受惊，本章不用。

## 生产与工程红线

1. **所有新动作不带棒生成**——星光棒一律运行时独立 prop 挂手锚点跟随（沿 M01 手电 held-prop 模式），杜绝即梦逐帧道具漂移。挂点=每动作一个静态手锚 + 少量关键帧偏移。
2. 帧规范沿用莱米管线：躯干宽归一、脚底线锚定、`facing=scaleX` 镜像、循环动作等高归一。
3. **演出层参数（锚点/时长/粒子/音效键）不得写进 `m02-starweb-warmth.json`**——该文件被双源字节相等测试钉死；放 `M02RenderContract` 或独立演出配置。
4. 演出状态一律写在事件响应处、位置/事实驱动（M01 耳态教训：不在可打断的异步等待之后置标志）；任何演出不阻塞输入，熟练玩家仍可十余秒穿过序章。
