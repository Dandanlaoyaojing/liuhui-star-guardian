## Phase 3B — 视图反馈（cc，编辑器 Preview 验证）

> 每个 Task 完成即：重启预览面板(手动)→无头探针数节点/读状态→截图肉眼验→checkpoint。收 R2/R3/R4 一并做（重做 onTouchEnd 时最省）。

- [ ] **T4 R3+R2 输入重整**：`onTouchEnd` 顶部 `const view = this.session.view` 快照(pre-tap 复用, 传入 nearestNodeId)；加 `activeTouchId`：`TOUCH_START` 记 `event.getID()`、`TOUCH_END` 仅当 id 匹配才处理并清空、`TOUCH_CANCEL` 清空 → 强制单触点。**验**：探针模拟单点仍点亮；双点只生效一次(电量只 -1)。
- [ ] **T5 R4 清理**：抽 `makeGraphicsNode(name,parent)`(UI_2D 层+UITransform+Graphics)去样板重复；`starGraphics` 保留为唯一缓存、渲染只经它(不再 getChildByName 双源)；`view` 注释标注 edges 只读。**验**：typecheck + 预览渲染不变。
- [ ] **T6 剩余电量 UI**：屏幕一角画剩余电量(棒尖光点数=`view.chargesLeft`)，每点一次减一。**验**：截图点前/点后电量数变化。
- [ ] **T7 衰减倒数光晕**：每颗亮星按 `life/lifeMax` 画一圈收缩的淡光晕(life 越低圈越小)；`frozen` 态光晕定住/换稳定色。**验**：点一颗后截图看邻居(decaying)光晕小于刚点亮的。
- [ ] **T8 失败可视化**：`status==="exhausted"` 时给个"漏光/暗场"提示 + 可点任意处重来(现有 resetBoard 已接)。**验**：故意点崩首板→截图看失败态→点击→回满电。
- [ ] **Checkpoint**：预览里首板体感完整(电量/衰减/失败可读)。
