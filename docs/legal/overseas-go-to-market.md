## 1. 各渠道行动清单

### A. 软件网页订阅 → Creem(可立刻开始)

**开通流程**(Creem 官方:Business Details → KYC/KYB → 收款账户 → Creem 审核 24–48h → 开通真实收款):
1. [ ] 在 creem.io 注册账号、建 Store
2. [ ] 先用 **test mode**(侧边栏切换):建产品、设价(USD/EUR)、接好 checkout、跑通测试 —— **KYB 通过前就能并行做集成**
3. [ ] Balance → Payout Account → 完成 **KYC/KYB 认证**
4. [ ] 填**对公银行账户**(⚠️ 账户持有人**必须 = 做商户的主体**:公司商户就用**对公账户**,别用法人个人卡)
5. [ ] 提交 → 等 Creem 合规审核(24–48h)→ 开通

**中国公司 KYB 要准备的材料**:
- [ ] 营业执照(统一社会信用代码,充当税号)
- [ ] 法定代表人身份证(KYC:清晰、不过期、姓名完全一致)
- [ ] 受益所有人 / 董事 身份信息
- [ ] 公司对公账户信息(**能收外汇的那个**)
- [ ] **公司英文/拼音名 = 银行对公账户登记的英文名**(一字不差;中国公司一般无"注册英文名",别自创。身份核验靠中文法定名 + 统一社会信用代码)
- [ ] 税务居民地:中国
- [ ] 产品网站 URL + 业务描述(让合规看到你卖什么)

**最容易被拒的点(先避开)**:
- ❌ 身份 ≠ 收款账户持有人(最致命);
- ❌ 证件模糊 / 过期 / 名称不一致;
- ❌ 产品网站太"空" —— 要有**定价、退款政策、隐私政策、联系方式**,否则可能打回。

**已知规则**:费率 3.9%+$0.40(首 €1000 免)、提现 1% 或 $7、资金压 7–12 天、每月 1/15 号打款、仅 USD/EUR 计价;中国公司收款落 **RMB(有汇损)**;公司本地银行账户**无上限**(个人支付宝才有 5万/笔、30–60万/年封顶)。

### B. 软件托管 → 海外(保证免 ICP)
- [ ] 托管放**中国大陆境外**(AWS/Vercel/Cloudflare,或云厂商的海外/香港区)
- [ ] 不面向中国大陆运营/销售 → 无需 ICP 备案 / 经营性 ICP 许可证 / App 备案
- [ ] ⚠️ 微信小程序版(China-facing)是**另一条线**,有自己的备案审核义务,与海外这套**分开**

### C. iOS App Store → 苹果企业号
- [ ] **申请 D-U-N-S 号**(免费;走 Apple 注册页入口,别找收费代办)
  - 先查公司是否**已有** DUNS;名称+地址必须与**营业执照完全一致**;预留几天到两周
- [ ] 注册 Apple Developer 企业号($99/年)
- [ ] 上架时**只勾选海外区**(游戏只要不上中国区 → **免版号**)
- [ ] 填税表 **W-8BEN-E** + 中美协定,降美国预扣

### D. Steam → Steamworks(全球 Steam)
- [ ] 注册 Steamworks,$100/款(满 $1000 销售额返还)
- [ ] 完成企业/身份验证 + 银行 + 税务问卷
- [ ] **W-8BEN-E + 中美协定**:把美国区预扣从 **30% 降到 ~10%**(别漏!)
- [ ] 全球 Steam 发行 → **免版号**(版号只针对"Steam 中国/蒸汽平台")
- [ ] 商店页"开发商/发行商"可填**工作室品牌名**(不必暴露公司全名)

## 2. 关键合规 / 税务提醒(贯穿所有渠道)

- **版号**:只在**中国区**卖收费游戏才要;只发海外 → 不需要。
- **ICP**:只针对中国托管/中国市场;海外托管+不卖中国 → 不需要。
- **收入落中国公司 = 服务出口收入**,统一要处理:
  - 对公**外汇收款申报**(国际收支申报;金额大需合同/发票/业务说明)
  - **企业所得税**
  - **增值税**:跨境数字服务出口通常零税率/免税,但**要做出口免税申报/备案**(非自动)
  - 银行对"从平台(Creem/苹果/Steam)收款"可能多问资金性质,松紧看开户行
- **美国预扣**:Apple/Steam 都是美国体系,务必用 **W-8BEN-E + 中美协定**降税。

## 4. 何时"升级到海外主体"(触发信号)

出现以下任一,就该考虑设**香港公司**(或美国 LLC)承接海外业务:

- 个人/公司收款撞到**结汇/汇损**痛点,或想**收入留境外**;
- 软件 **Stripe 网页直收**成为大头(香港原生 Stripe + USD 不换汇更顺);
- 要**对外融资**或把 **IP 放境外**;
- 规模化后想要更干净的**银行 + 税务**结构。

> 香港 vs 美国:对中国股东,**香港在"被冻结/被针对/地缘"上更安全**;美国更省钱但有 Mercury 美国地址门槛 + 美国税表。升级时再按当时情况定。
